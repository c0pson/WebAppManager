# Web App Manger

## What is this?

Simple and lightweight Python application for keeping and managing your web applications. The idea behind is to simplify the process of creating, removing and modifying `.desktop` entries.

### Requirements

In order to install and use application properly you need to have installed:

 - **Chromium Web Browser**
 - **Python** `>= 3.14.7` (Probably works on lower versions but it wasn't tested)
